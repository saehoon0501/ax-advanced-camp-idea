# 1) Orchestrator-Agent Context Boundary (계층적 컨텍스트 관리)

## 개발 Principle (Context Engineering 관점)

- **Context Isolation**: Orchestrator와 Sub-agent는 서로 다른 컨텍스트 공간에서 동작한다. Sub-agent의 내부 대화(tool calls, 중간 추론)가 Orchestrator를 오염시키지 않아야 한다.
- **Summary-Only Propagation**: Sub-agent가 작업을 완료하면, **최종 요약 메시지만** Orchestrator로 전달된다. 이를 통해 여러 agent를 순차적으로 호출해도 컨텍스트가 폭발하지 않는다.
- **Hierarchical Memory**: Orchestrator는 "무엇이 완료되었는가"를 기억하고, Sub-agent는 "어떻게 완료했는가"의 세부사항을 담당한다.
- **Scalable Multi-Agent**: 이 패턴 없이는 2-3번의 agent 호출만으로도 컨텍스트가 소진된다.

## 시나리오 (Long-Running Agent 맥락)

### 배경

Orchestrator-Workers 아키텍처에서:

```
User: "Build a blog app"
    │
    ▼
┌─────────────────────────────────────────────────────────────────┐
│  ORCHESTRATOR                                                    │
│  - Router가 Initializer Agent 선택                              │
│  - Initializer 완료 후 결과 수신                                 │
│  - 다음 User 입력 시 Coding Agent 선택 가능                      │
└─────────────────────────────────────────────────────────────────┘
```

### 문제: Context Explosion

만약 Sub-agent의 모든 메시지를 Orchestrator가 유지한다면:

```python
# Initializer Agent 내부 대화 (예시)
messages = [
    User: "Build a blog app",
    AI: "I'll analyze requirements and create feature_list.json",
    Tool: bash("mkdir -p src"),
    ToolResult: "Created directory",
    AI: "Now creating feature_list.json with 15 features",
    Tool: write_file("feature_list.json", "...5000 chars..."),
    ToolResult: "File written successfully",
    AI: "Creating progress.md",
    Tool: write_file("progress.md", "..."),
    ToolResult: "File written",
    AI: "Creating init.sh",
    Tool: write_file("init.sh", "..."),
    ToolResult: "File written",
    AI: "✓ Project initialized with 15 features, ready for coding"
]
# → 12개 메시지, ~8000 tokens
```

이 모든 것이 Orchestrator에 축적되면:
- 2-3번의 agent 호출 후 컨텍스트 소진
- 대부분은 이미 완료된 작업의 세부사항 (불필요)

### 해결책: Summary-Only Return

```python
# orchestrator.py의 실제 구현
def _initializer_node(self, state: OrchestratorState) -> dict:
    result = self.initializer_agent.invoke({
        "messages": state.get("messages", []),
    })
    # 오직 마지막 메시지만 Orchestrator로 전달!
    return {"messages": [AIMessage(content=result["messages"][-1].content)]}
```

결과:

```
Orchestrator State:
  messages: [
    User: "Build a blog app",
    AI: "Routing to initializer: Project needs setup",
    AI: "✓ Project initialized with 15 features, ready for coding"  ← Summary only
  ]
# → 3개 메시지, ~200 tokens
```

## 학습 목표

1. **계층적 컨텍스트 분리**의 필요성을 이해한다.
2. Sub-agent → Orchestrator 메시지 전달 패턴을 구현한다.
3. "Summary message"의 품질이 시스템 전체에 미치는 영향을 이해한다.
4. 다양한 요약 전략 (마지막 메시지, 구조화된 요약, 핵심 결정사항 추출)을 비교한다.

## 요구사항 (Student Task)

### Task 1: Agent Result Summarizer

`extract_agent_summary(agent_result: dict, strategy: str) -> AIMessage`를 구현하라.

**Strategies**:

1. `"last_message"`: 마지막 AIMessage의 content 반환 (현재 구현)
2. `"structured"`: 구조화된 요약 생성 (completed, files_changed, next_steps)
3. `"key_decisions"`: 중요한 결정사항만 추출

**입력 예시**:

```python
agent_result = {
    "messages": [
        HumanMessage(content="Build a blog"),
        AIMessage(content="I'll create the project structure"),
        ToolMessage(content="Created feature_list.json"),
        AIMessage(content="Created progress.md"),
        ToolMessage(content="File written"),
        AIMessage(content="✓ Initialized: 15 features, files: feature_list.json, progress.md, init.sh")
    ]
}
```

**출력 (strategy="structured")**:

```python
AIMessage(content="""
## Agent Summary
**Status**: Completed
**Files created**: feature_list.json, progress.md, init.sh
**Key output**: 15 features defined
**Next steps**: Ready for coding agent
""")
```

### Task 2: Orchestrator Node Wrapper

`create_agent_node(agent, summary_strategy: str) -> Callable`를 구현하라.

**동작**:

1. Agent를 invoke
2. 결과에서 summary 추출
3. Orchestrator state에 summary만 반환

```python
def create_agent_node(agent, summary_strategy: str = "last_message"):
    def node(state: OrchestratorState) -> dict:
        result = agent.invoke({
            "messages": state.get("messages", []),
            "todo_list": [],
        })
        summary = extract_agent_summary(result, summary_strategy)
        return {"messages": [summary]}
    return node
```

### Task 3: Summary Quality Validator

`validate_summary_quality(summary: str, agent_result: dict) -> ValidationReport`를 구현하라.

**검증 항목**:

1. **Completeness**: 주요 작업이 언급되었는가?
2. **Actionability**: 다음 단계가 명확한가?
3. **Brevity**: 불필요한 세부사항이 제거되었는가?

### 구조화된 요약 추출

```python
def extract_structured_summary(messages: list[BaseMessage]) -> str:
    """Agent 메시지에서 구조화된 요약 생성"""

    # 1. Tool 호출에서 파일 변경 추출
    files_changed = []
    for msg in messages:
        if isinstance(msg, ToolMessage):
            # 파일 작업 감지
            if "written" in msg.content.lower() or "created" in msg.content.lower():
                files_changed.append(extract_filename(msg))

    # 2. 마지막 AI 메시지에서 상태 추출
    last_ai = next((m for m in reversed(messages) if isinstance(m, AIMessage)), None)
    status = "Completed" if last_ai and ("✓" in last_ai.content or "완료" in last_ai.content) else "In Progress"

    # 3. 구조화된 요약 생성
    return f"""## Agent Summary
**Status**: {status}
**Files changed**: {', '.join(files_changed) or 'None'}
**Summary**: {last_ai.content if last_ai else 'No summary'}
"""
```

### Token 절약 효과 측정

```python
def measure_context_savings(full_messages: list, summary_only: list) -> dict:
    """요약 사용 시 절약되는 토큰 계산"""
    full_tokens = sum(len(m.content) // 4 for m in full_messages)
    summary_tokens = sum(len(m.content) // 4 for m in summary_only)

    return {
        "full_tokens": full_tokens,
        "summary_tokens": summary_tokens,
        "saved_tokens": full_tokens - summary_tokens,
        "reduction_percent": round((1 - summary_tokens / full_tokens) * 100, 1)
    }
```

## 실패 모드 / 주의점

### 1. Summary가 너무 짧음

**문제**: "Done." 같은 무의미한 요약
**영향**: Orchestrator가 다음 결정을 내리기 위한 정보 부족
**해결**: Summary 품질 검증 + Agent prompt에 요약 형식 명시

```python
# Agent system prompt에 추가
"""
When you complete your task, your FINAL message should include:
1. What was accomplished (specific files, counts)
2. Current project state
3. Suggested next steps
"""
```

### 2. 중요한 에러 정보 손실

**문제**: Agent 중간에 에러가 있었지만 마지막 메시지만 보면 성공으로 보임
**해결**: 에러/경고 메시지 별도 추출

```python
def extract_with_errors(messages: list) -> AIMessage:
    errors = [m for m in messages if "error" in m.content.lower()]
    last_msg = messages[-1]

    if errors:
        return AIMessage(content=f"{last_msg.content}\n\n⚠️ Warnings: {len(errors)} issues encountered")
    return AIMessage(content=last_msg.content)
```

### 3. 결정 사항 손실

**문제**: Agent가 "JWT 대신 Session 사용" 같은 결정을 했지만 요약에 없음
**영향**: 다음 Agent가 동일한 결정을 다시 고민
**해결**: Key decisions 추출 전략 사용

### 4. 순환 참조 위험

**문제**: Orchestrator 메시지가 다시 Agent에게 전달될 때 혼란
**해결**: Agent에게 전달 시 명확한 역할 구분

def test_extract_last_message():
    """기본 전략: 마지막 메시지"""
    messages = [
        HumanMessage(content="Build app"),
        AIMessage(content="Starting..."),
        AIMessage(content="✓ Done with 10 features"),

    summary = extract_agent_summary({"messages": messages}, "last_message")
    assert "10 features" in summary.content


def test_extract_structured_summary():
    """구조화된 요약"""
    messages = [
        HumanMessage(content="Build app"),
        AIMessage(content="Creating files"),
        ToolMessage(content="feature_list.json written"),
        AIMessage(content="✓ Complete"),
    ]

    summary = extract_agent_summary({"messages": messages}, "structured")
    assert "feature_list.json" in summary.content
    assert "Completed" in summary.content


def test_context_savings():
    """토큰 절약 효과"""
    # 10개 메시지 (각 500자) vs 1개 요약 (100자)
    full_messages = [AIMessage(content="x" * 500) for _ in range(10)]
    summary = [AIMessage(content="Summary: " + "x" * 100)]

    savings = measure_context_savings(full_messages, summary)
    assert savings["reduction_percent"] > 90


def test_error_preservation():
    """에러 정보 보존"""
    messages = [
        AIMessage(content="Starting"),
        ToolMessage(content="Error: file not found"),
        AIMessage(content="Recovered and completed"),
    ]

    summary = extract_agent_summary({"messages": messages}, "with_errors")
    assert "Warning" in summary.content or "error" in summary.content.lower()

## 실전 적용 (Main Scenario)

### Orchestrator에서의 사용

```python
class LongRunningOrchestrator:
    def __init__(self, llm, summary_strategy: str = "last_message"):
        self.summary_strategy = summary_strategy
        # ...

    def _initializer_node(self, state: OrchestratorState) -> dict:
        result = self.initializer_agent.invoke(...)
        summary = extract_agent_summary(result, self.summary_strategy)
        return {"messages": [summary]}

    def _coding_node(self, state: OrchestratorState) -> dict:
        result = self.coding_agent.invoke(...)
        summary = extract_agent_summary(result, self.summary_strategy)
        return {"messages": [summary]}
```

### Multi-Agent 시나리오에서의 효과

```
Session 1: User → Orchestrator → Initializer → Summary → Orchestrator
Session 2: User → Orchestrator → Coding → Summary → Orchestrator
Session 3: User → Orchestrator → Coding → Summary → Orchestrator
...

Without summary: 3 sessions × ~8000 tokens = 24000+ tokens (context exhausted)
With summary: 3 sessions × ~200 tokens = 600 tokens (sustainable)
```
