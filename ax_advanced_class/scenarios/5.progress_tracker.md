# 5) Progress Tracker (Initializer Agent - Progress 파일 및 Init Script 생성)

## 개발 Principle (Context Engineering 관점)

- **Progress File as Context Bridge**: progress.md 파일은 세션 간의 맥락을 전달하는 핵심 수단이다. "왜 이 결정을 했는지", "다음엔 무엇을 해야 하는지" 같은 맥락을 담는다.
- **Init Script as Session Continuity**: init.sh 스크립트는 새 세션 시작 시 Coding Agent가 프로젝트 상태를 빠르게 파악할 수 있게 돕는다.
- **Structured Format for Parsing**: Coding Agent가 파싱할 수 있도록 일관된 형식으로 작성해야 한다.
- **Foundation for Future Sessions**: Initializer Agent가 생성하는 파일들은 이후 Coding Agent들이 컨텍스트를 복원하는 데 사용된다.

## 시나리오 (Long-Running Agent 맥락)

### 배경

Anthropic 아티클의 핵심 패턴:

- **Initializer Agent**: 프로젝트 초기화 시 progress.md 파일 및 init.sh 스크립트 생성

### progress.md 초기 템플릿

Initializer Agent가 생성해야 하는 progress.md 파일 형식:

```markdown
# Project Progress: {project_name}

## Session 1 (2025-01-06 08:00) - Initialization

**Completed**: Project initialization
**Files created**: feature_list.json, init.sh, progress.md
**Next priority**: feature-001 ({first_high_priority_feature})
**Notes**:

- Created {N} features in feature_list.json
- Ready for first coding session
```

### init.sh 템플릿

Initializer Agent가 생성해야 하는 init.sh 스크립트:

```bash
#!/bin/bash
# Session Continuity Script
# Purpose: Restore project context for new sessions

# Check git commit history to see what's been completed
git log --oneline -20

# Display current progress
cat progress.md

# Show feature list
cat feature_list.json
```

**필수 요소**:

- `#!/bin/bash` (shebang)
- `git log` (최근 커밋 확인)
- `cat progress.md` (진행 상황 표시)
- `cat feature_list.json` (기능 목록 표시)

3. 구조화된 형식이 향후 파싱을 쉽게 만드는 원리를 이해한다.

**출력 파일 형식**:

```bash
cat progress.md

cat feature_list.json
```

**필수 요소**:

- `#!/bin/bash` - Shebang (스크립트 실행을 위해 필수)
- `git log` - 최근 커밋 히스토리 확인
- `cat progress.md` - 진행 상황 파일 표시
- `cat feature_list.json` - 기능 목록 파일 표시

## 구현 가이드

### Progress File 초기 생성

```python
from datetime import datetime

def create_initial_progress_file(project_name: str, feature_count: int, first_feature_id: str):
    timestamp = datetime.now().strftime("%Y-%m-%d %H:%M")
    content = f"""# Project Progress: {project_name}

## Session 1 ({timestamp}) - Initialization

**Completed**: Project initialization
**Files created**: feature_list.json, init.sh, progress.md
**Next priority**: {first_feature_id}
**Notes**:

- Created {feature_count} features in feature_list.json
- Ready for first coding session
"""
    with open("progress.md", "w") as f:
        f.write(content)
```

### Init Script 생성

```python
def create_init_script():
    content = """#!/bin/bash
# Session Continuity Script
# Purpose: Restore project context for new sessions

# Check git commit history
git log --oneline -20

# Display current progress
cat progress.md

# Show feature list
cat feature_list.json
"""
    with open("init.sh", "w") as f:
        f.write(content)

    # Make executable
    import os
    os.chmod("init.sh", 0o755)
```

## 실패 모드 / 주의점

### 1. progress.md 형식 일관성

**문제**: 비정형 형식으로 작성하면 Coding Agent가 파싱 불가
**해결**: 템플릿 형식 엄격히 준수

### 2. 필수 필드 누락

**문제**: **Next priority**를 빠뜨리면 Coding Agent가 어디서부터 시작해야 할지 모름
**해결**: 모든 필수 필드 (Completed, Next priority) 포함

### 3. 불명확한 Notes

**문제**: Notes에 너무 일반적인 내용 작성
**해결**: 구체적인 결정 사항, 대기 중인 이슈, 의존성 등 기록

### 4. init.sh 필수 명령어 누락

**문제**: git log, cat progress.md, cat feature_list.json 중 하나라도 빠지면 Coding Agent가 컨텍스트 복원 불가
**해결**: 모든 필수 명령어 포함

### 5. init.sh Shebang 누락

**문제**: `#!/bin/bash` 없이 스크립트 작성
**해결**: 파일 첫 줄에 반드시 shebang 포함

## 테스트 (제공/권장)

### 제공 테스트

```python
def test_progress_file_format(tmp_path):
    os.chdir(tmp_path)
    create_initial_progress_file("test-project", 20, "feature-001")

    content = Path("progress.md").read_text()
    assert "# Project Progress: test-project" in content
    assert "Session 1" in content
    assert "feature-001" in content
    assert "20 features" in content
    assert "**Completed**:" in content
    assert "**Next priority**:" in content

def test_progress_file_parseable(tmp_path):
    os.chdir(tmp_path)
    create_initial_progress_file("test-project", 20, "feature-001")

    content = Path("progress.md").read_text()
    # Should be parseable by Coding Agent
    assert "**Next priority**: feature-001" in content

def test_init_script_format(tmp_path):
    os.chdir(tmp_path)
    create_init_script()

    content = Path("init.sh").read_text()
    # Required elements
    assert content.startswith("#!/bin/bash") or content.startswith("#!/bin/sh")
    assert "git log" in content
    assert "progress.md" in content
    assert "feature_list.json" in content

def test_init_script_executable(tmp_path):
    os.chdir(tmp_path)
    create_init_script()

    import stat
    mode = Path("init.sh").stat().st_mode
    assert mode & stat.S_IXUSR  # User executable
```

## 실전 적용 (Main Scenario)

```
At the end of initialization:
1. Create feature_list.json with all features

2. Create progress.md with:
   - Project name
   - Timestamp
   - Feature count
   - First high-priority feature as next priority
   - Notes about initialization

3. Create init.sh with:
   - Shebang (#!/bin/bash)
   - git log command (show recent commits)
   - cat progress.md (display progress)

```
