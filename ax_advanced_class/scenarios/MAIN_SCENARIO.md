# Main Scenario: CLI AI Coding Tool

이 문서는 “우리가 만들 **CLI 기반 AI 코딩 툴**이 어떤 경험을 제공해야 하는지”만 담고 있어요.

- 프로젝트/시나리오 소개(인덱스, 합쳐지는 방식, 개념도)는 `README.md`에서 확인해 주세요.
- 각 시나리오의 구현 상세/실습 과제/산출물은 `scenarios/*.md`에 있습니다.

## 이 CLI는 무엇을 해주나요?

이 CLI는 단순히 모델을 한 번 호출하는 도구가 아니라,
여러 번 실행해도 개발이 **끊기지 않게** 도와주는 “세션형 코딩 파트너”를 목표로 합니다.

한 번 실행할 때마다, 다음을 자연스럽게 해주는 게 핵심이에요:

1. 지금 상태를 빠르게 파악하고(콜드 스타트), 어디서부터 이어갈지 잡아준다.
2. 이번 실행에서 “무엇 하나”를 끝내도록 작업 범위를 정리해준다.
3. 결과를 검증하고, 다음 실행이 바로 이어받을 수 있도록 인계 기록을 남긴다.
4. 문제가 생기면 조용히 넘어가지 않고, 왜 실패했는지와 다음 행동을 알려준다.

## Definition of Done (Integrated Run Works)

1. 단일 CLI/orchestrator 엔트리포인트로 `init`을 실행할 수 있어야 하며, 이후 세션에 필요한 지속 상태를 포함한 실행 가능한 workspace를 만든다.
2. 동일한 엔트리포인트로 `code`를 반복 실행할 수 있어야 하며(최소 3회), 각 실행은 “콜드 스타트”(이전 채팅 메모리 없음)로 시작해도 repo 산출물(파일 + git)만으로 올바르게 재개한다.
3. 각 `code` 실행은 자기완결적이어야 하며: 컨텍스트 복원 → 다음 작업 선택 → 작업 수행 → 완료 검증(선택한 gate) → 다음 실행이 추측 없이 이어갈 수 있도록 인계 기록을 남긴다.
4. 실행이 실패하면(검증 실패, tool 에러, 불일치 등) 명확하고 실행 가능한 오류 메시지로 실패해야 하며, progress/state를 조용히 전진시키지 않는다.
