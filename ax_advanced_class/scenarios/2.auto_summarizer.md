# 2) Auto Summarizer (Agent 내부 대화 압축)

## 개발 Principle (Context Engineering 관점)

- **Long-Running Agent Sessions**: Coding Agent가 복잡한 기능을 구현할 때, 수십 번의 tool call과 디버깅 과정을 거친다. 이 과정에서 컨텍스트가 빠르게 소진된다.
- **Lossy Compression with Meaning Preservation**: 오래된 대화를 삭제하는 대신, **핵심 의미를 보존한 요약**으로 압축한다. 이를 통해 중요한 결정사항과 맥락을 유지하면서 토큰을 절약한다.
- **Hierarchical Memory**: 최근 메시지는 원문 유지 (정확도), 과거 메시지는 요약으로 유지 (효율성).
- **Middleware Pattern**: 이 기능은 **middleware로 구현**되어 Initializer Agent와 Coding Agent 모두에 자동 적용된다.

## 시나리오 (Long-Running Agent 맥락)

### 배경

Coding Agent가 "feature-005: Message Streaming" 기능을 구현 중입니다:

```
[Turn 1] AI: "I'll implement message streaming"
[Turn 2] Tool: read_file("src/api.ts") → 2000 chars
[Turn 3] AI: "I see the API structure. Let me create the streaming endpoint"
[Turn 4] Tool: write_file("src/streaming.ts", ...) → 1500 chars
[Turn 5] Tool: bash("npm test") → 5000 chars of test output
[Turn 6] AI: "Tests failing. Let me check the error"
[Turn 7] Tool: read_file("src/streaming.ts") → 1500 chars
[Turn 8] AI: "Found the bug - missing async handler"
[Turn 9] Tool: edit_file(...) → 500 chars
[Turn 10] Tool: bash("npm test") → 5000 chars
[Turn 11] AI: "Still failing. Different error now..."
... (20 more turns of debugging) ...
[Turn 30] AI: "Finally! All tests passing"
```

**문제**: 30턴 × 평균 2000 tokens = **60,000 tokens** (컨텍스트 한계 근접)

### 적용 대상

이 middleware는 **모든 sub-agent에 적용**됩니다:

| Agent                 | 적용 이유                                            |
| --------------------- | ---------------------------------------------------- |
| **Initializer Agent** | 대규모 feature list 생성 시 많은 tool call 발생 가능 |
| **Coding Agent**      | 디버깅, 테스트 반복으로 긴 세션 발생                 |

Middleware로 구현되므로 agent 코드 수정 없이 자동 적용됩니다.

### 해결책: Progressive Summarization

```
[Original: 30 turns, 60k tokens]
         │
         ▼ (Auto Summarizer Middleware)
[Compressed: 8 items, 15k tokens]

┌─────────────────────────────────────────────────────────────────┐
│ SUMMARIZED CONTEXT (inserted as SystemMessage)                  │
│                                                                  │
│ ## Previous Work Summary                                         │
│ - Read src/api.ts: Found REST API structure with auth middleware│
│ - Created src/streaming.ts: WebSocket-based streaming endpoint  │
│ - Debugging: Fixed 3 issues (async handler, event format, auth) │
│ - Decision: Using WebSocket over SSE for bidirectional support  │
│ - Current state: Basic streaming works, edge cases remain       │
└─────────────────────────────────────────────────────────────────┘
│
├── [Turn 26] Recent context preserved as-is
├── [Turn 27] Recent context preserved as-is
├── [Turn 28] Recent context preserved as-is
├── [Turn 29] Recent context preserved as-is
└── [Turn 30] AI: "Finally! All tests passing"
```

## 학습 목표

1. **Summarization vs Truncation**: 삭제 대신 요약의 장점을 이해한다.
2. **Middleware Integration**: Agent에 투명하게 적용되는 압축 패턴을 구현한다.
3. **Summary Schema Design**: 후속 추론에 유용한 요약 구조를 설계한다.
4. **Trigger Conditions**: 언제 요약을 실행할지 결정하는 기준을 정의한다.

## 요구사항 (Student Task)

### Task 1: Summarization Middleware

`SummarizerMiddleware` 클래스를 구현하라.

**동작**:

1. Agent의 메시지 리스트 모니터링
2. Token threshold 초과 시 자동 요약 실행
3. 오래된 메시지를 요약으로 대체
4. System Prompt와 최근 N개 메시지는 보존

```python
class SummarizerMiddleware:
    def __init__(
        self,
        llm: BaseChatModel,
        max_tokens: int = 50000,
        preserve_recent: int = 5,
        summary_format: str = "structured"
    ):
        self.llm = llm
        self.max_tokens = max_tokens
        self.preserve_recent = preserve_recent
        self.summary_format = summary_format

    def __call__(self, state: AgentState) -> AgentState:
        messages = state.get("messages", [])
        current_tokens = self.count_tokens(messages)

        if current_tokens <= self.max_tokens:
            return state  # No compression needed

        # Compress older messages
        compressed = self.compress_messages(messages)
        return {**state, "messages": compressed}
```

**Format Options**:

2. `"structured"`: 섹션별 정리 (권장)
3. `"bullet"`: 간단한 bullet points

### Task 3: Compression Trigger Logic

`should_compress(messages: list, config: CompressionConfig) -> bool`를 구현하라.

**Trigger Conditions**:

```python
@dataclass
class CompressionConfig:
    max_tokens: int = 50000          # 절대 한계
    target_tokens: int = 30000       # 압축 후 목표
    min_messages_to_compress: int = 10  # 최소 메시지 수
    preserve_recent: int = 5         # 보존할 최근 메시지
```

**로직**:

```python
def should_compress(messages: list, config: CompressionConfig) -> bool:
    current_tokens = count_tokens(messages)

    # 1. 토큰 한계 초과
    if current_tokens > config.max_tokens:
        return True

    # 2. 압축할 만한 메시지가 충분한가
    compressible = len(messages) - config.preserve_recent - 1  # -1 for system prompt
    if compressible < config.min_messages_to_compress:
        return False

    # 3. 목표 대비 50% 초과 시 압축
    if current_tokens > config.target_tokens * 1.5:
        return True

    return False
```

### Token Counting (Simple Version)

```python
def count_tokens(messages: list[BaseMessage]) -> int:
    """Approximate token count (chars / 4)"""
    return sum(len(m.content) for m in messages) // 4
```

### Message Compression Flow

```python
def compress_messages(self, messages: list[BaseMessage]) -> list[BaseMessage]:
    """Compress older messages into a summary"""

    # 1. Separate components
    system_prompt = messages[0] if messages else None
    recent = messages[-self.preserve_recent:] if len(messages) > self.preserve_recent else messages[1:]
    to_summarize = messages[1:-self.preserve_recent] if len(messages) > self.preserve_recent + 1 else []

    if not to_summarize:
        return messages  # Nothing to compress

    # 2. Generate summary
    summary_text = self.generate_summary(to_summarize)

    # 3. Create summary message
    summary_message = SystemMessage(content=f"""
## Previous Conversation Summary
{summary_text}

---
The conversation continues below with recent messages:
""")

    # 4. Reconstruct message list
    result = []
    if system_prompt:
        result.append(system_prompt)
    result.append(summary_message)
    result.extend(recent)

    return result
```

**문제**: 중요한 디버깅 맥락이 요약에서 누락

**해결**:


### 2. Summary Drift (요약의 요약)

**문제**: 여러 번 압축하면 정보가 점점 변형됨
**해결**:

```python

def compress_messages(self, messages):
    # 기존 summary message 감지
    existing_summary = next(
        (m for m in messages if "Previous Conversation Summary" in m.content),
        None
    )
    if existing_summary:
        # 기존 요약은 유지, 새 메시지만 처리
        ...
```

### 3. 요약 실행 시점의 지연

**문제**: LLM 요약 호출로 Agent 응답이 느려짐
**해결**:

- 비동기 요약 (백그라운드 실행)
- 캐싱 (동일 메시지 재요약 방지)
- 간단한 규칙 기반 요약을 먼저 시도

### 4. System Prompt와 Summary 충돌

**문제**: Summary가 System Prompt처럼 보여서 Agent가 혼란
**해결**: 명확한 구분자와 라벨 사용

```python
summary_message = SystemMessage(content=f"""
[CONTEXT: This is a summary of earlier work in this session, not instructions]

{summary_text}

[END CONTEXT - Continue with the task]
""")
```

### 5. Tool Output 중복 압축

**문제**: Tool Output Trimmer (시나리오 3)가 이미 압축한 내용을 다시 요약
**해결**: Middleware 순서 조정 - Trimmer가 먼저 실행

```python
middleware=[
```

## 테스트 (제공/권장)

### 제공 테스트

```python
def test_no_compression_under_threshold():
    """임계값 미만이면 압축 안 함"""
    middleware = SummarizerMiddleware(llm, max_tokens=10000)
    messages = [SystemMessage(content="System"), HumanMessage(content="Hi")]

    result = middleware({"messages": messages})
    assert len(result["messages"]) == 2  # 변화 없음


def test_compression_over_threshold():
    """임계값 초과 시 압축"""
    middleware = SummarizerMiddleware(llm, max_tokens=1000, preserve_recent=2)

    # 긴 대화 생성
    messages = [SystemMessage(content="System")]
    messages.extend([AIMessage(content="x" * 500) for _ in range(10)])

    result = middleware({"messages": messages})

    # System + Summary + Recent 2 = 4 messages
    assert len(result["messages"]) < len(messages)
    assert "Summary" in result["messages"][1].content


def test_preserves_system_prompt():
    """System Prompt는 항상 보존"""
    middleware = SummarizerMiddleware(llm, max_tokens=100)
    system = SystemMessage(content="You are a helpful assistant")
    messages = [system] + [AIMessage(content="x" * 1000) for _ in range(10)]

    result = middleware({"messages": messages})

    assert result["messages"][0].content == system.content


def test_preserves_recent_messages():
    """최근 N개 메시지는 원문 보존"""
    middleware = SummarizerMiddleware(llm, max_tokens=100, preserve_recent=3)
    messages = [SystemMessage(content="System")]
    recent_3 = [AIMessage(content=f"Recent {i}") for i in range(3)]
    old = [AIMessage(content=f"Old {i}") for i in range(10)]

    all_messages = messages + old + recent_3
    result = middleware({"messages": all_messages})

    # 최근 3개는 원문 그대로
    for i, msg in enumerate(recent_3):
        assert result["messages"][-(3-i)].content == msg.content


def test_summary_contains_key_info():
    """요약에 핵심 정보 포함"""
    middleware = SummarizerMiddleware(llm, max_tokens=100)
    messages = [
        SystemMessage(content="System"),
        AIMessage(content="Reading file src/api.ts"),
        ToolMessage(content="File content: REST API..."),
        AIMessage(content="Decision: Using JWT for auth"),
        AIMessage(content="Error: Missing await keyword"),
        AIMessage(content="Fixed the async issue"),
    ]

    result = middleware({"messages": messages})
    summary = result["messages"][1].content

    # 핵심 정보가 요약에 포함되어야 함
    assert "api.ts" in summary or "file" in summary.lower()
    assert "JWT" in summary or "auth" in summary.lower()
```

```python
def incremental_summarize(existing_summary: str, new_messages: list) -> str:
    prompt = f"""
    Existing summary:
    {existing_summary}

    New messages to incorporate:
    {format_messages(new_messages)}

    Updated summary (integrate new information):

    return llm.invoke(prompt).content
```

```python
def score_message_importance(message: BaseMessage) -> float:
    score = 0.5  # Base score

    if "error" in message.content.lower():
        score += 0.3
    if "decision" in message.content.lower():
        score += 0.2
    if isinstance(message, ToolMessage) and "written" in message.content:
        score += 0.2

    return min(score, 1.0)
```

### Coding Agent에서의 효과

```
Before (no summarization):
- Session starts: 5k tokens (system prompt + context)
- After 30 turns: 65k tokens (approaching limit)
- Feature incomplete, session must end

After (with summarization):
- Session starts: 5k tokens
- After 15 turns: 35k tokens → compression triggers
- After compression: 20k tokens (summary + recent 5)
- Continue working: 15 more turns possible
- Feature complete within single session
```
