# 8) Session Task Planner (세션 내 작업 계획 및 추적)

## 개발 Principle (Context Engineering 관점)

- **Planning as Context Anchor**: 에이전트가 "다음에 뭘 해야 하지?"를 매번 재계산하면 컨텍스트를 낭비한다. **세션 시작 시 계획을 세우고 참조**하면 일관된 진행이 가능하다.
- **Todolist as Working Memory**: 컨텍스트 윈도우가 길어지면 에이전트는 초기 의도를 잊어버린다. **명시적 todolist**는 "지금 해야 할 일"을 상기시키는 **외부 메모리** 역할을 한다.
- **Progress Visibility**: 사용자와 다음 세션의 에이전트 모두 "현재 어디까지 왔는가"를 한눈에 파악해야 한다. Todolist의 상태(pending/in_progress/completed)가 이를 명확히 보여준다.
- **Preventing Scope Drift**: Todolist에 없는 작업을 시작하면 scope creep이 발생한다. "Todolist에 있는 것만 한다"는 규칙이 **집중력을 유지**시킨다.

## 시나리오 (Long-Running Agent 맥락)

### 배경

Anthropic 아티클의 핵심 인사이트:

> **문제**: 에이전트가 기능 구현 중 "이것도 해야겠다, 저것도 해야겠다"하며 산만해짐 → 결국 아무것도 완성 못 함

**해결책**: 세션 시작 시 **명확한 계획을 세우고**, 그 계획을 **체계적으로 추적**하며, 계획에 없는 작업은 **하지 않는다**.

### 예시: Before & After

#### ❌ Before (No Task Planning)

```
[Session starts]
Agent: "feature-003을 구현하겠습니다!"
→ NewChatButton 컴포넌트 만들기 시작
→ "아, 스타일도 필요하네" → CSS 작성
→ "테스트도 만들어야지" → 테스트 작성 시작
→ "어, 이 API 호출이 이상하네" → API 수정
→ "근데 여기 버그가 있네" → 다른 컴포넌트 수정
→ 컨텍스트 소진

결과: NewChatButton 80% 완성, 테스트 50% 완성,
      API 변경 커밋 안 됨, 다른 버그 수정 중간에 멈춤
      → 다음 세션: "뭘 하고 있었던 거야...?"
```

#### ✅ After (With Task Planning)

```
[Session starts]
Agent: "feature-003을 구현하겠습니다. 먼저 계획을 세웁니다."

Todo List:
1. [ ] NewChatButton 컴포넌트 생성
2. [ ] 클릭 핸들러 구현
3. [ ] 스타일 적용
4. [ ] 단위 테스트 작성
5. [ ] E2E 테스트로 검증
6. [ ] feature_list.json 업데이트

Agent: "1번부터 시작합니다."
→ [x] NewChatButton 컴포넌트 생성 ✓

Agent: "1번 완료, 2번 진행합니다."
→ [x] 클릭 핸들러 구현 ✓

(중간에 다른 버그 발견)
Agent: "이건 현재 todolist에 없습니다. progress.md에 메모만 하고 넘어갑니다."

... (모든 항목 완료) ...

결과: feature-003 100% 완성, 테스트 통과, 커밋 완료
      → 다음 세션: "Todolist 완료됨. feature-004 시작!"
```

### Coding Agent의 Todolist 워크플로우

```
┌─────────────────────────────────────────────────────────────────┐
│  SESSION START                                                   │
│  1. State Recovery (Scenario 6)                                 │
│  2. Feature Selection (Scenario 7)                              │
│  3. ★ Task Planning (Scenario 8) ← 이 시나리오                  │
│     - Feature의 steps를 todolist로 변환                         │
│     - 추가 필요한 작업 식별 (테스트, 문서화 등)                  │
│     - 우선순위 정렬                                              │
└───────────────────────────┬─────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────────┐
│  SESSION WORK                                                    │
│  Loop until todolist complete:                                   │
│    1. 현재 in_progress 항목 확인                                │
│    2. 해당 작업 수행                                            │
│    3. 완료되면 completed로 마킹                                 │
│    4. 다음 pending 항목을 in_progress로 변경                    │
│    5. ★ Todolist에 없는 작업은 하지 않음 ★                     │
└───────────────────────────┬─────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────────┐
│  SESSION END                                                     │
│  1. Todolist 완료 상태 확인                                     │
│  2. Clean State Committer (Scenario 9)                          │
└─────────────────────────────────────────────────────────────────┘
```

## 학습 목표

1. Feature의 steps를 실행 가능한 todolist로 변환하는 방법을 익힌다.
2. Todolist 상태 관리 (pending → in_progress → completed) 패턴을 구현한다.
3. Scope drift를 방지하는 "todolist-only" 규칙을 적용한다.
4. 세션 내 진행 상황을 사용자에게 시각적으로 보여주는 방법을 구현한다.

### Task 1: Feature → Todolist 변환

`create_session_todolist(feature: dict) -> List[TodoItem]`을 구현하라.

**입력 예시**:

```json

  "steps": [

  ]
}
```

**출력 예시**:

```python
[
    TodoItem(content="Create NewChatButton component", status="pending"),
    TodoItem(content="Implement click handler to create conversation", status="pending"),
    TodoItem(content="Add unique ID generation for conversations", status="pending"),
```

**변환 규칙**:

1. Feature의 각 `step`을 구현 작업으로 변환
2. 암묵적 작업 추가: 테스트 작성, feature_list 업데이트
3. 논리적 순서로 정렬 (UI → 로직 → 테스트 → 문서화)

### Task 2: Todolist 상태 관리

`TodolistManager` 클래스를 구현하라.

```python
@dataclass
class TodoItem:
    content: str
    status: Literal["pending", "in_progress", "completed"]
    created_at: datetime
    completed_at: Optional[datetime] = None

class TodolistManager:
    def __init__(self, items: List[TodoItem]):
        self.items = items

    def get_current_task(self) -> Optional[TodoItem]:
        """현재 in_progress 상태의 작업 반환"""
        ...

    def start_next_task(self) -> Optional[TodoItem]:
        """다음 pending 작업을 in_progress로 변경하고 반환"""
        ...

    def complete_current_task(self) -> bool:
        """현재 작업을 completed로 마킹"""
        ...

    def is_all_complete(self) -> bool:
        """모든 작업이 completed인지 확인"""
        ...

    def get_progress(self) -> dict:
        """진행 상황 통계 반환"""
        # {"total": 8, "completed": 3, "in_progress": 1, "pending": 4}
        ...

    def to_markdown(self) -> str:
        """마크다운 형식으로 출력"""
        # ## Session Todo
        # - [x] Create component
        # - [ ] Implement handler (in progress)
        # - [ ] Add tests
        ...
```

**상태 전이 규칙**:

```
pending → in_progress → completed
   │            │
   │            └── complete_current_task()
   └── start_next_task()
```

**제약**:

- 동시에 `in_progress`는 최대 1개
- `completed`에서 다른 상태로 되돌릴 수 없음
- `pending`에서 바로 `completed`로 갈 수 없음

### Task 3: Scope Guard

`check_task_in_scope(action: str, todolist: List[TodoItem]) -> bool`을 구현하라.

**목적**: 에이전트가 수행하려는 작업이 현재 todolist에 있는지 검증

**예시**:

```python
todolist = [
    TodoItem(content="Create NewChatButton component", status="in_progress"),
    TodoItem(content="Write unit tests", status="pending"),
]

# 허용
check_task_in_scope("Creating NewChatButton.tsx", todolist)  # True
check_task_in_scope("Writing test for NewChatButton", todolist)  # True

# 거부 (todolist에 없음)

check_task_in_scope("Refactoring API client", todolist)  # False
```

**판단 로직**:

1. Todolist의 각 item content에서 키워드 추출
2. 수행하려는 action에서 키워드 추출
3. 키워드 매칭 여부 확인 (유사도 기반)

## 구현 가이드

### Feature Steps → Implementation Tasks 변환

```python
def steps_to_implementation_tasks(feature: dict) -> List[str]:
    """Feature의 verification steps를 구현 작업으로 변환"""
    tasks = []

    for step in feature["steps"]:
        step_lower = step.lower()

        if "click" in step_lower:
            # "Click X button" → "Create X component" + "Implement click handler"
            component = extract_component_name(step)
            tasks.append(f"Create {component} component")
            tasks.append(f"Implement click handler for {component}")

        elif "verify" in step_lower:
            # "Verify X appears" → 검증 대상 구현
            subject = extract_verification_subject(step)
            tasks.append(f"Implement {subject}")

        elif "navigate" in step_lower:
            # "Navigate to X" → 라우팅 구현
            route = extract_route(step)
            tasks.append(f"Add route for {route}")

    # 암묵적 작업 추가
    tasks.append("Write unit tests")
    tasks.append("Run E2E test to verify feature")
    tasks.append("Update feature_list.json passes=true")

    return tasks
```

### Todolist 영속성 (세션 중 저장)

```python
def save_todolist(manager: TodolistManager, path: str = ".session_todo.json"):
    """세션 중 todolist 상태 저장 (컨텍스트 손실 대비)"""
    data = {
        "feature_id": manager.feature_id,
        "items": [
            {
                "content": item.content,
                "status": item.status,
                "created_at": item.created_at.isoformat(),
                "completed_at": item.completed_at.isoformat() if item.completed_at else None,
            }
            for item in manager.items
        ]
    }
    Path(path).write_text(json.dumps(data, indent=2))

def load_todolist(path: str = ".session_todo.json") -> Optional[TodolistManager]:
    """저장된 todolist 복원"""
    if not Path(path).exists():
        return None

    data = json.loads(Path(path).read_text())
    items = [
        TodoItem(
            content=item["content"],
            status=item["status"],
            created_at=datetime.fromisoformat(item["created_at"]),
            completed_at=datetime.fromisoformat(item["completed_at"]) if item["completed_at"] else None,
        )
        for item in data["items"]
    ]
    return TodolistManager(items, feature_id=data["feature_id"])
```

### System Prompt에 Todolist 주입

```python
def inject_todolist_to_prompt(base_prompt: str, manager: TodolistManager) -> str:
    """System prompt에 현재 todolist 상태 추가"""
    todolist_section = f"""
## Current Session Todolist

{manager.to_markdown()}

### Rules:
1. Work ONLY on items in this todolist
2. Complete one item at a time (mark as done before starting next)
3. If you discover new work needed, add it to progress.md notes, NOT to this todolist
4. Your session is complete when all items are checked

### Current Task:
{manager.get_current_task().content if manager.get_current_task() else "Select next pending task"}
"""
    return base_prompt + "\n" + todolist_section
```

## 실패 모드 / 주의점

### 1. 에이전트가 Todolist를 무시하고 다른 작업 시작

**문제**: "이것도 해야 할 것 같아서요"
**해결**: Scope Guard + System Prompt 강화

```
CRITICAL: You can ONLY work on tasks in your todolist.
If you attempt to do anything else, I will stop you.
Discovered issues go to progress.md notes, NOT current work.
```

### 2. Todolist가 너무 세분화됨

**문제**: 50개의 micro-task로 쪼개서 관리 오버헤드 증가
**해결**: 적정 granularity 유지 (5-15개 tasks per feature)

```python
MAX_TASKS = 15

def create_session_todolist(feature: dict) -> List[TodoItem]:
    tasks = steps_to_implementation_tasks(feature)

    if len(tasks) > MAX_TASKS:
        # 유사한 작업 그룹화
        tasks = consolidate_similar_tasks(tasks)

    return tasks
```

### 3. Todolist가 너무 추상적임

**문제**: "Implement feature" 같은 모호한 항목
**해결**: 각 항목은 **검증 가능한 결과물**을 가져야 함

```python
def validate_task_specificity(task: str) -> bool:
    """작업이 충분히 구체적인지 검증"""
    vague_patterns = ["implement", "do", "make", "work on", "handle"]

    for pattern in vague_patterns:
        if task.lower().startswith(pattern) and len(task.split()) < 4:
            return False  # 너무 모호함

    return True
```

### 4. 완료 표시를 너무 빨리 함

**문제**: 실제로 안 끝났는데 "완료"로 마킹
**해결**: 완료 전 검증 단계

```python
def complete_current_task(self, verification: str = None) -> bool:
    """검증 정보와 함께 완료 처리"""
    current = self.get_current_task()
    if not current:
        return False

    # 검증 요구
    if verification is None:
        raise ValueError("Must provide verification of completion")

    current.status = "completed"
    current.completed_at = datetime.now()
    current.verification = verification  # "Test passed" or "File created"

    return True
```

### 5. 세션이 중단되면 Todolist 손실

**문제**: 컨텍스트 윈도우 소진으로 세션이 갑자기 종료
**해결**: 주기적 저장 + 세션 시작 시 복원

```python
# 매 작업 완료 후 저장
manager.complete_current_task(verification="...")
save_todolist(manager)  # 즉시 저장

# 세션 시작 시 복원 시도
restored = load_todolist()
if restored:
    print(f"Restored todolist: {restored.get_progress()}")
```

### 제공 테스트

```python
def test_create_session_todolist():
    """Feature → Todolist 변환"""
    feature = {
        "id": "feature-003",
        "description": "New chat button",
        "steps": [
            "Click the 'New Chat' button",
            "Verify conversation is created",
        ]
    }

    todolist = create_session_todolist(feature)

    assert len(todolist) >= 4  # steps + implicit tasks
    assert all(item.status == "pending" for item in todolist)
    assert any("test" in item.content.lower() for item in todolist)


def test_todolist_state_transitions():
    """상태 전이 테스트"""
    manager = TodolistManager([
        TodoItem(content="Task 1", status="pending", created_at=datetime.now()),
        TodoItem(content="Task 2", status="pending", created_at=datetime.now()),
    ])

    # 초기 상태
    assert manager.get_current_task() is None

    # 첫 작업 시작
    task = manager.start_next_task()
    assert task.content == "Task 1"
    assert task.status == "in_progress"

    # 완료 처리
    manager.complete_current_task()
    assert manager.items[0].status == "completed"

    # 다음 작업
    task = manager.start_next_task()
    assert task.content == "Task 2"


def test_only_one_in_progress():
    """동시에 하나만 in_progress"""
    manager = TodolistManager([
        TodoItem(content="Task 1", status="pending", created_at=datetime.now()),
        TodoItem(content="Task 2", status="pending", created_at=datetime.now()),
    ])

    manager.start_next_task()

    # 또 시작하려고 하면 실패
    with pytest.raises(ValueError):
        manager.start_next_task()


def test_scope_guard():
    """Todolist 외 작업 차단"""
    todolist = [
        TodoItem(content="Create NewChatButton component", status="in_progress", created_at=datetime.now()),
    ]

    assert check_task_in_scope("Creating NewChatButton.tsx", todolist) == True
    assert check_task_in_scope("Fixing auth bug", todolist) == False


def test_progress_calculation():
    """진행률 계산"""
    manager = TodolistManager([
        TodoItem(content="Task 1", status="completed", created_at=datetime.now()),
        TodoItem(content="Task 2", status="completed", created_at=datetime.now()),
        TodoItem(content="Task 3", status="in_progress", created_at=datetime.now()),
        TodoItem(content="Task 4", status="pending", created_at=datetime.now()),
    ])

    progress = manager.get_progress()

    assert progress["total"] == 4
    assert progress["completed"] == 2
    assert progress["in_progress"] == 1
    assert progress["pending"] == 1
```

## 확장 과제 (선택)

### 1. 예상 시간 추정

각 task에 예상 시간을 부여하고 진행률 표시:

```python
@dataclass
class TodoItem:
    content: str
    status: str
    estimated_minutes: int = 30
    actual_minutes: Optional[int] = None

def render_progress_with_time(manager: TodolistManager) -> str:
    total_est = sum(item.estimated_minutes for item in manager.items)
    completed_est = sum(item.estimated_minutes for item in manager.items if item.status == "completed")

    return f"Progress: {completed_est}/{total_est} minutes estimated"
```

### 2. 동적 Task 추가

세션 중 필요한 작업 발견 시 안전하게 추가:

```python
def add_discovered_task(manager: TodolistManager, content: str, reason: str) -> bool:
    """발견된 작업을 todolist에 추가 (로깅 포함)"""
    new_item = TodoItem(
        content=content,
        status="pending",
        created_at=datetime.now(),
        added_reason=reason,  # "Discovered during implementation"
    )

    manager.items.append(new_item)
    print(f"⚠️ Added discovered task: {content}")
    print(f"   Reason: {reason}")

    return True
```

### 3. 의존성 추적

Task 간 의존성을 관리:

```python
@dataclass
class TodoItem:
    content: str
    status: str
    depends_on: List[str] = field(default_factory=list)

def get_available_tasks(manager: TodolistManager) -> List[TodoItem]:
    """의존성이 충족된 pending 작업만 반환"""
    completed_contents = {item.content for item in manager.items if item.status == "completed"}

    return [
        item for item in manager.items
        if item.status == "pending"
        and all(dep in completed_contents for dep in item.depends_on)
    ]
```

### Coding Agent의 Todolist 워크플로우

```python
def coding_agent_session():
    # 1. State Recovery (Scenario 6)
    state = recover_session_state()
    feature_list = load_json("feature_list.json")

    # 2. Feature Selection (Scenario 7)
    feature = select_next_feature(feature_list)
    if feature is None:
        print("All features complete!")
        return

    # 3. Task Planning (Scenario 8) ★
    # 이전 세션의 todolist 복원 시도
    manager = load_todolist()

    if manager is None or manager.feature_id != feature["id"]:
        # 새 todolist 생성
        todolist = create_session_todolist(feature)
        manager = TodolistManager(todolist, feature_id=feature["id"])
        print(f"Created new todolist with {len(todolist)} tasks")
    else:
        print(f"Restored todolist: {manager.get_progress()}")

    # 4. Work Loop
    while not manager.is_all_complete():
        # 현재 작업 가져오기
        current = manager.get_current_task()
        if current is None:
            current = manager.start_next_task()

        print(render_progress(manager))
        print(f"\n→ Working on: {current.content}")

        # 작업 수행 (에이전트 호출)
        result = agent.work_on(current.content)

        # Scope guard
        if not check_task_in_scope(result.action, manager.items):
            print(f"⚠️ Out of scope: {result.action}")
            print("Adding to progress.md notes instead")
            append_to_progress_notes(result.action)
            continue

        # 완료 처리
        if result.success:
            manager.complete_current_task(verification=result.verification)
            save_todolist(manager)  # 즉시 저장

    # 5. Clean State (Scenario 9)
    print("✅ All tasks complete!")
    cleanup_session_todolist()  # .session_todo.json 삭제
```
