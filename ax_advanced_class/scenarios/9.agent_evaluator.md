# 9) Agent Evaluator (에이전트 행동 검증)

## 개발 Principle (Context Engineering 관점)

- **Code ≠ Correctness**: 에이전트가 코드를 작성했다고 해서 올바른 결과물을 생성한 것은 아니다. 에이전트는 형식적으로는 "완료"처럼 보이지만 실제로는 품질이 낮은 결과물을 생성할 수 있다.
- **Deterministic + LLM-based**: 검증은 두 가지로 나뉜다. **코드 기반 검증**(스키마, 형식, 규칙)은 빠르고 결정적이다. **LLM 기반 검증**(품질, 의미)은 주관적 판단이 필요한 부분을 평가한다.
- **Artifact-Based Evaluation**: 에이전트의 행동을 직접 테스트하기보다, 에이전트가 생성한 **산출물(artifact)**을 검증한다. 이를 통해 세션 간 일관성을 확보한다.
- **Weighted Scoring**: 각 평가 항목에 가중치를 부여하여 종합 점수를 계산한다. 핵심 요소(스키마 적합성)와 부가 요소(품질)를 구분한다.

## 시나리오 (Long-Running Agent 맥락)

### 배경

Anthropic 아티클의 핵심 인사이트:

> 에이전트가 "완료"라고 선언해도 실제로는 버그가 있거나 불완전할 수 있다. **체계적인 검증 시스템**이 없으면 에이전트의 출력을 신뢰할 수 없다.

## 구현 가이드

### Schema Grader 핵심 로직

```python
REQUIRED_FIELDS = {"id", "category", "description", "priority", "steps", "passes", "dependencies"}
VALID_CATEGORIES = {"functional", "ui", "performance", "security"}
VALID_PRIORITIES = {"high", "medium", "low"}
ID_PATTERN = re.compile(r"^feature-\d+$")

def _validate_feature(self, feature: dict, index: int, seen_ids: set) -> list[str]:
    errors = []
    prefix = f"Feature [{index}]"

    # 필수 필드 검사
    missing = REQUIRED_FIELDS - set(feature.keys())
    if missing:
        errors.append(f"{prefix}: Missing required fields: {missing}")

    # ID 형식 검사
    if "id" in feature:
        fid = feature["id"]
        if not ID_PATTERN.match(fid):
            errors.append(f"{prefix}: 'id' must match pattern 'feature-NNN'")
        elif fid in seen_ids:
            errors.append(f"{prefix}: Duplicate id '{fid}'")
        else:
            seen_ids.add(fid)

    return errors
```

### Dependency Grader: 순환 의존성 탐지

```python
def _detect_cycles(self, features: list[dict]) -> list[str]:
    """DFS로 순환 의존성 탐지"""
    graph = {f["id"]: f.get("dependencies", []) for f in features}

    visited = set()
    rec_stack = set()
    cycles = []

    def dfs(node: str, path: list[str]) -> bool:
        visited.add(node)
        rec_stack.add(node)

        for neighbor in graph.get(node, []):
            if neighbor not in visited:
                if dfs(neighbor, path + [neighbor]):
                    return True
            elif neighbor in rec_stack:
                # 순환 발견!
                cycle = path[path.index(neighbor):] + [neighbor]
                cycles.append(f"Circular: {' -> '.join(cycle)}")
                return True

        rec_stack.remove(node)
        return False

    for fid in graph:
        if fid not in visited:
            dfs(fid, [fid])

    return cycles
```

### LLM Response 파싱

````python
def _parse_scores(self, content: str) -> FeatureScores:
    """LLM 응답에서 JSON 점수 추출"""
    # 직접 JSON 파싱 시도
    try:
        data = json.loads(content)
        return FeatureScores(**data)
    except json.JSONDecodeError:
        pass

    # Markdown 코드 블록에서 추출
    json_match = re.search(r"```(?:json)?\s*(\{.*?\})\s*```", content, re.DOTALL)
    if json_match:
        data = json.loads(json_match.group(1))
        return FeatureScores(**data)

    # 텍스트 어디서든 JSON 객체 찾기
    json_match = re.search(r"\{[^{}]*\}", content)
    if json_match:
        data = json.loads(json_match.group(0))
        return FeatureScores(**data)

    raise ValueError(f"Could not parse scores: {content[:200]}")
````

```python
REQUIRED_PATTERNS = {

    "rm_commands": r"rm\s+",

def grade(self, init_script_path: Path) -> InitScriptGradeResult:
    content = init_script_path.read_text()

    # 필수 요소 확인
    checks_passed = sum(
        1 for pattern in REQUIRED_PATTERNS.values()
        if re.search(pattern, content, re.MULTILINE)

            penalty += 0.1
```


### 2. 샘플링 편향

**문제**: 무작위 샘플이 전체를 대표하지 못함
**해결**: 카테고리별 층화 샘플링

```python
def stratified_sample(features: list[dict], sample_size: int) -> list[dict]:
    """카테고리별 비율 유지하며 샘플링"""
    by_category = defaultdict(list)
    for f in features:
        by_category[f["category"]].append(f)

    sampled = []
    for cat, items in by_category.items():
        ratio = len(items) / len(features)
        n = max(1, int(sample_size * ratio))
        sampled.extend(random.sample(items, min(n, len(items))))

    return sampled[:sample_size]
```

## 실전 적용 (Main Scenario)

### Initializer Agent 평가 파이프라인

```python
def evaluate_initializer_output(workspace: Path, test_case: dict) -> EvalReport:
    """Initializer Agent 실행 후 산출물 평가"""

    # 1. 에이전트 실행
    _run_agent(test_case, workspace)

    # 2. 산출물 경로
    feature_list_path = workspace / "feature_list.json"
    progress_path = workspace / "progress.md"
    init_script_path = workspace / "init.sh"

    # 3. Code-based 평가 (병렬 실행 가능)
    schema_result = SchemaGrader().grade(feature_list_path)
    progress_result = ProgressGrader().grade(progress_path)
    init_script_result = InitScriptGrader().grade(init_script_path)

    # 4. Schema 통과 시에만 추가 평가
    if schema_result.passed:
        features = json.load(open(feature_list_path))
        dependency_result = DependencyGrader().grade(features)
        quality_result = QualityGrader().grade(features, sample_size=10)

    # 5. 종합 점수 계산
    overall_score = (
        schema_result.score * 0.25 +
        dependency_result.score * 0.15 +
        quality_result.score * 0.20 +
        progress_result.score * 0.10 +
        init_script_result.score * 0.15
    )

    return EvalReport(passed=all_passed, overall_score=overall_score, ...)
```
